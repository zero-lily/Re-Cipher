# Re信号 Chrome拡張（Manifest V3）

YouTubeの通常コメント・ライブチャットで `Re信号:` から始まる暗号文を検出し、自動復号します。接頭辞を紫、復号本文を緑で表示します。オフにすると元コメントへ戻ります。

## インストール（ストア不要）
1. ZIPを展開します。
2. Chromeで `chrome://extensions` を開きます。
3. 右上の「デベロッパーモード」をオンにします。
4. 「パッケージ化されていない拡張機能を読み込む」から展開したフォルダを指定します。
5. YouTubeのタブを再読み込みし、拡張アイコンをクリックして自動復号をオンにします。

## GitHubとの連携
- [固定公開データ](https://github.com/zero-lily/Re-Cipher/blob/main/codec-v3.json)から辞書JSONを読み込めます。初回・約24時間ごとに自動確認します。ポップアップから手動更新もできます。
- 読み込めない場合は同梱辞書で復号します。
- 辞書の `version` は `3` に固定し、既存語句の符号を**変更せず**、未使用コードに追加します。重複や不正な符号は拒否します。
- **復号アルゴリズム（JavaScript）変更には拡張機能の更新が必要**です。Chrome Web Storeポリシーで外部JS実行は禁止されており、GitHubから実行コードはロードしません。
- リンク先辞書ファイルの変更はGitHub Pagesと拡張機能が自動同期するわけではありません。サイトの辞書を変更する場合、同じ辞書をこのJSONにも反映してください。

## 対象と注意点
- `www.youtube.com` / `m.youtube.com` のコメント・チャット要素を対象とします。埋め込みプレイヤーやYouTube Studioは対象外です。
- YouTube側のHTML構造の変更、新形式コメント、ライブチャットのiframe構造によって表示できない場合があります。
- 復号は閲覧中のページ内で実行され、コメント本文は外部送信しません。GitHubには辞書データの取得要求のみ行います。
- 一般公開前に、ご自身の動画で通常コメントとライブチャット双方の確認をおすすめします。

## v1.1.1 表示修正

Chromeのポップアップが縦長で極端に狭くなる問題を修正しました。ポップアップを390px幅で表示します。

## v1.1.2: ライブチャットの送信先検出修正

- ライブチャットのiframeを個別に検出し、送信先を確認します。
- 新旧のチャット入力欄（`contenteditable`、`plaintext-only`、`#input`）に対応します。
- YouTubeへのアクセス権限と `webNavigation` を使用して、表示済みのチャットフレームを検出します。
- 二段階確認・既存の下書きの上書き防止は維持します。
- 入力欄が一意に特定できない場合は送信せず、手動送信を案内します。

更新後は `chrome://extensions` で拡張機能を更新し、YouTubeタブも再読み込みしてください。Chromeが追加権限の承認を求める場合があります。

## v1.1.3 表示設定・手動復号

- Chrome拡張の新規インストールでは自動復号がデフォルトでオン。既存のユーザー設定は維持します。
- 「Re信号の投稿を非表示」は自動復号とは独立したスイッチです。オンにすると、Re信号から始まるライブチャット・動画コメントの投稿全体を隠します。解除すると元通り表示します。
- 自動復号オフ時も `Re信号:` は紫、未復号の暗号本文はオレンジ色で表示します。
- 拡張機能のポップアップに「復号」欄、接頭辞挿入、復号文コピーを追加しました。
- 暗号化・YouTubeへの二段階送信確認・辞書形式は変更していません。

※ オン・オフ操作はブラウザの閲覧表示を変更するだけです。YouTube上の投稿本文は変更しません。

## v1.1.4 通常動画コメントへの送信修正

- 動画の「コメントする…」が閉じている場合、「暗号化して送信…」操作後に入力欄を開いて候補を再検出します。
- `contenteditable` 型と `textarea` 型のコメント入力欄に対応します。
- 既存の下書きは上書きせず、投稿前の送信先・内容の二段階確認は維持します。
- YouTubeのUIが変わり入力欄を特定できない場合は、手動で「コメントする…」をクリックする案内を表示します。
