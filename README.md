# Re:Cipher — リゼロ風ネタバレ変換サイト

リゼロの同時視聴に向けた、非公式のブラウザ完結型の換字ツールです。`Re:` で始まる文字列をコピーし、内容を知りたい人だけが復号できます。

## GitHub Pages への公開

1. GitHub で **Public** の新規リポジトリ（例: `rezero-cipher`）を作成する。
2. このフォルダの `index.html` と `.nojekyll` をリポジトリのルートへアップロードしコミットする。README.md と dictionary.json は任意（説明・検証用）。
3. リポジトリの **Settings → Pages → Build and deployment** で **Deploy from a branch** を選択。
4. Branch: **main**、Folder: **/(root)** を選択して **Save**。
5. デプロイ後のURLは `https://<ユーザー名>.github.io/<リポジトリ名>/`。

ビルド、APIキー、サーバー、外部フォントは不要です。サイト本体は `index.html` の1ファイルで動作します。

## フォーマット・互換性

- 識別子：`Re:`
- 符号アルファベット：リゼロを連想させる64種類のカタカナ・漢字・記号
- 7個の1文字符号、その他は2文字符号。未登録のUnicode文字は「・」＋4桁の64進数符号で記述。
- 原文（漢字、カタカナ、ひらがな、記号、改行、絵文字）をUnicodeコードポイント単位で可逆変換。
- 辞書は **v1として固定**。一度公開した `Re:` の符号対応を途中で入れ替えると、過去のコメントが読めなくなります。
- 前回の64文字試作辞書とは文字セットが異なるため、旧試作で作成した暗号文と **互換ではありません**。
- 特定のUnicode互換文字を正規化すると元の文字と区別できなくなるため、暗号本文へのNFKC正規化は禁止です。

### 注意

これはネタバレの偶発的な閲覧を避けるための**難読化**です。暗号学的な秘匿性はありません。閲覧者は変換サイトを使えば誰でも復号できます。配信者やコミュニティのネタバレ禁止ルールを優先してください。

チャット実データ7,006件について、暗号化→復号結果が元の文章と一致することをテスト済み。対象動画のコメントやチャットログ自体はこのサイトに同梱していません。
